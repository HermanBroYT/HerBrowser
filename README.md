# HerБраузер для Windows 10 и 11

Настольная версия HerБраузера (Chromium внутри). Установщик и портативная версия собираются на GitHub.

## Что есть
- Вкладки и приватные вкладки (отдельный временный профиль), восстановление вкладок при запуске
- Главная: погода (Яндекс), поиск только в Яндексе, ярлыки сайтов
- «Защита сайтов»: ✅ безопасный сайт (HTTPS), 🚫 небезопасный (HTTP) с предупреждением
- Закладки, история (очистка только в «Истории»), загрузки без «.bin» и выбор папки загрузок
- Перевод страницы на русский, копирование ссылки, поиск на странице, печать, масштаб
- Тема: светлая / тёмная / как в системе и свои цвета, «О приложении» с копированием версии
- Экраны «Нет подключения» и «Белый список»

## Горячие клавиши
Ctrl+T новая вкладка · Ctrl+W закрыть · Ctrl+L адрес · Ctrl+F найти · Ctrl+D закладка · Ctrl+H история · Ctrl+J загрузки · F5 обновить · F12 инструменты · Ctrl +/−/0 масштаб · Ctrl+Tab переключение вкладок

## Сборка
GitHub Actions (windows.yml): `npm install` и `npx electron-builder --win --x64`. Результат: `HerBrowser-Setup-1.7.0.exe` и `HerBrowser-1.7.0-portable.exe`.
