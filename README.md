# HerБраузер 1.5

Быстрый. Удобный. Для тебя. Браузер для Android на WebView.

**Android:** 5.0 (API 21) и новее, рассчитан на Android 14. Ярлык сайта на рабочем столе: Android 8.0+. Разрешение на уведомления: Android 13+.

## Добавлено в 1.5
- Копирование ссылки на любом сайте: кнопка «Копировать» в меню «⋮», долгое нажатие на «Защита сайтов», а при нажатии на адресную строку вся ссылка выделяется.
- Загрузки: «Загрузки» → «⚙ Настройки» (справа вверху) → «Выбрать папку» → «Сохранить». Новые файлы появляются в выбранной папке.
- Перевод: на сайте меню «⋮» → «Перевести» (на русский). «Показать оригинал» возвращает страницу.
- «Защита сайтов» слева вверху: ✅ безопасный сайт (HTTPS), 🚫 небезопасный (HTTP). Для небезопасного сайта или HTML-файла выходит предупреждение: «Рискнуть для проверки (не советую)» и «Перейти на страницу (рекомендую)».
- Новый выбор цвета: «Оформление» → «Выбрать цвет» (круг, готовые цвета, «Сохранить»).

## Исправлено в 1.5
- После установки или сброса кэша ничего не видно (ни поиска, ни кнопок), пока не пройдены приветствие и разрешения.
- Разрешения: пока не всё включено, «Продолжить» недоступна, есть только «Пропустить». Когда всё включено, «Пропустить» исчезает, а «Продолжить» разблокируется.
- «Приватная вкладка: история не сохраняется» показывается только в «Приватности», а в обычных «Вкладках» больше не появляется после поиска.
- Строка поиска при нажатии поднимается наверх без перекрытия: вводимый текст виден.
