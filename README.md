# HerБраузер 1.3

Быстрый. Удобный. Для тебя. Браузер для Android на WebView.

## Исправлено в 1.3
- «Главный экран (Домой)»: ярлык сайта или мессенджера создаётся на рабочем столе, уведомления сайта можно включить или выключить.
- Загрузки: нормальные имена и расширения (без .bin/.bit), фото, видео и музыка в своих папках, APK открываются для установки.
- Стабильность: вкладки восстанавливаются после перезапуска, браузер переживает сбой отрисовки страницы.
- Оформление: после выбора цветов и нажатия «Назад» всё приложение сразу обновляется.

## Новое в 1.3
- Вкладки как в Opera: сверху переключатель «Вкладки — Приватность», карточки с миниатюрами.
- Первый запуск и сброс кэша: аватарка поднимается, появляется текст, затем кнопка «Продолжить», затем экран разрешений (камера, уведомления, местоположение, микрофон) с кнопкой «Пропустить».
- Больше анимаций и эффектов на кнопках.

## Важно
- Уведомления сайтов работают, пока браузер запущен.
- Пароли хранятся без шифрования.
