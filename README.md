# HerБраузер 1.7

Быстрый. Удобный. Для тебя. Браузер для Android на WebView.

**Android:** 5.0 (API 21) и новее, рассчитан на Android 14. Ярлык сайта на рабочем столе: Android 8.0+. Разрешение на уведомления: Android 13+.

## Новое в 1.7
- Погода в левом верхнем углу главного экрана: температура в градусах (Яндекс.Погода).
- Родительский контроль: дата рождения, режимы Kids (4–11), Teenager (12–15) и обычный (16–18), роль родителя (Мама/Папа) и имя.
- Сканирование QR-кода: переход на страницу или в приложение (Меню → «Сканировать QR-код»).
- Кнопка «Скачать видео» убрана из меню.

## Исправлено в 1.7
- Пароли: Email (имя пользователя) виден, пароль скрыт; показать его можно после подтверждения блокировкой экрана. Если блокировки экрана нет, пароль остаётся скрытым.
- Очистка истории только через раздел «История» (отдельной кнопки в «Памяти» нет).
- Убрана полоска при входе в поиск.

## Сборка через GitHub Actions

1. Загрузите содержимое папки `HerBrowser 1.7` в корень GitHub-репозитория.
2. Откройте вкладку **Actions** и запустите workflow **Android CI** (или сделайте push).
3. После успешной сборки APK будет доступен в разделе **Artifacts** запуска workflow.

Workflow проверяет наличие файлов проекта, использует JDK 17 и Gradle 8.5,
собирает `assembleRelease` и проверяет, что APK действительно создан.
Он запускается при `push`, `pull_request` и вручную через `workflow_dispatch`.

Если проект загружается ZIP-архивом, поместите архив с именем
`HerBrowser-project.zip` в корень репозитория. Архив может содержать
внутреннюю папку проекта.


## Изменение в этой сборке
- Полностью удалён экран «Скачать видео», его элементы интерфейса и отдельный модуль загрузчика видео. Обычные загрузки файлов браузера остаются.

### Как установить на Android:
1. Нажмите на кнопку выше, чтобы скачать файл `HerBrowser-1.5.apk`.
2. Откройте скачанный файл в шторке уведомлений или в папке «Загрузки».
3. Разрешите установку из неизвестных источников для вашего браузера, если система запросит.
4. Нажмите **Установить**.
