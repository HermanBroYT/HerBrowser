# HerБраузер 1.7

Быстрый. Удобный. Для тебя. Браузер для Android на WebView.

**Android:** 5.0 (API 21) и новее, рассчитан на Android 14. Ярлык сайта на рабочем столе: Android 8.0+. Разрешение на уведомления: Android 13+.

## Обновление 1.7
- В меню ублен пункт «Скачать видео»; функция загрузки видео вне главного меню сохранена.
- Если на телефоне нет блокировки экрана, в карточке пароля отображается email/имя пользователя, а пароль остаётся скрытым. При включённой блокировке пароль открывается после подтверждения.
- Родительские возрастные диапазоны уточнены: Kids (4–11), Teenager (12–15), обычный (16–18).

## Возможности 1.6
- **Погода** слева вверху на главной: температура в градусах. Данные Яндекс.Погоды (нужен API-ключ: Настройки → Погода), без ключа используется Open-Meteo. Нужно разрешение на местоположение.
- **Родительский контроль** (Настройки → Безопасность): PIN-код вводится два раза; указываются роль (Мама/Папа), имя и дата рождения ребёнка. Режимы: Kids (4–11, все ограничения), Teenager (12–15, история и пароли защищены), обычный (16–18). Ограничения: очистка истории, удаление загрузок и паролей, запрещённые сайты, защита от удаления приложения. Действует до 18 лет.
- **QR-код**: меню → «Сканировать QR-код»: перейти на страницу или открыть в приложении.
- **Скачать видео**: YouTube и VK Видео по ссылке, выбор качества, видео или только звук. Меню и меню «⋮» на сайте.
- Оформление: «Выбрать цвет» → круг и готовые цвета → «Сохранить».
- Безопасность: Родительский контроль, Защита приложений паролем (✅/❌), Установка неизвестных приложений (✅/❌).
- Экономия аккумулятора: порог 1–90%, включается сама.

## Исправлено и сохранено в 1.7
- Пароли: список и email видны всегда, сам пароль открывается только после блокировки экрана (без неё скрыт).
- Кнопки «Очистить историю» в настройках больше нет: очистка только через «Историю».
- Убрана полоска при входе в поиск.
