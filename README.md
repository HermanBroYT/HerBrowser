# HerБраузер 1.6

Быстрый. Удобный. Для тебя. Браузер для Android на WebView.

**Android:** 5.0 (API 21) и новее, рассчитан на Android 14. Ярлык сайта на рабочем столе: Android 8.0+. Разрешение на уведомления: Android 13+.

## Добавлено в 1.6
- Оформление: «Выбрать цвет» (круг, готовые цвета) → «Сохранить» для основного и фонового цвета.
- Родительский контроль (Настройки → Безопасность): PIN-код вводится два раза, дальше настраиваются ограничения: очистка истории, удаление загрузок и паролей, запрещённые сайты, защита от удаления приложения. Обязательно указывается год рождения ребёнка: контроль действует до 18 лет. Снять ограничения может только тот, кто знает PIN-код.
- Пароли: смотреть их можно только после подтверждения блокировкой экрана телефона.
- Безопасность в Настройках: Родительский контроль; Защита приложений паролем (✅/❌); Установка неизвестных приложений (✅/❌).
- Экономия аккумулятора: Настройки → «Экономия аккумулятора», порог от 1% до 90%, «Сохранить». При достижении порога экономия включается сама, её можно выключить или изменить процент.
